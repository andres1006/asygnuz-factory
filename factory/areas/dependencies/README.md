# Área — Dependencies

Capacidad transversal para mantener dependencias actualizadas y reducir riesgo
de CVEs sin romper CI. Opera como sweep periódico, reacción a alertas de
Security y soporte pre-release.

Esta área no reemplaza QA, Security ni DevOps: produce PRs y bitácora para que
esas áreas revisen regresiones, hallazgos y efectos de CI/runtime.
