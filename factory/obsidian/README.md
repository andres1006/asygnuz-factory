# Obsidian

Esta carpeta contiene mapas de navegación para usar el repo como vault de
Obsidian sin duplicar conocimiento normativo.

## Regla

Los MOCs (`maps/`) son índices derivados. La fuente de verdad sigue en las
carpetas canónicas de `factory/`.

Si una nota descubre una decisión, regla o cambio estable, debe promoverse a:

- `factory/decisions/` si es una decisión global;
- `factory/governance/` si cambia gates/gobierno;
- `factory/standards/` si cambia política técnica;
- `factory/operations/` si cambia operación;
- `factory/changes/` si evoluciona el template o la fábrica.

## Uso

Abrí la raíz del repo como vault de Obsidian y empezá por:

- `factory/obsidian/maps/MOC-factory.md`
- `factory/obsidian/maps/MOC-agents.md`
- `factory/obsidian/maps/MOC-quality-gates.md`
- `factory/obsidian/maps/MOC-template-evolution.md`
